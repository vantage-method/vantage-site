Assumptions and open questions

Assumptions

  • Same content, platform styling. Migrated sites keep their pages, copy, images and URLs. They are rendered in the platform's page system with each brand's own logo and colors, not rebuilt pixel for pixel from the old WordPress themes. A pixel-exact rebuild of an old theme is a separate design job.
  • Forms. Gravity Forms are rebuilt as platform forms with submissions stored in the CMS and emailed to the same people. Slate and Populi embeds carry over as embeds.
  • The BGU shop. bethanygu.edu runs a small WooCommerce shop. It moves as a Stripe-backed shop on the platform, or is retired if unused.
  • JustDisciple search traffic. 421 articles are the asset. Migration includes a one-to-one redirect map and a post-launch ranking check at 30 days.
  • Email tools. Nurture sequences are built in the tool each site already uses. Consolidating to one tool is a separate line.
  • Access needed. WP Engine account access for each install, DNS access for each domain, GoFundMe Pro admin (already in place), and admin access to Klaviyo, Slate and the email tools.
